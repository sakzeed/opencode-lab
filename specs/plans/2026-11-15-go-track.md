# Go Track Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** เพิ่ม track Go 5 บทใน `docs/go/` พร้อมโค้ดจริง `labs/labps/` (CLI อ่าน `/proc`) ที่มี test และ CI job `go`

**Architecture:** `labps` เป็น Go module แยกใน `labs/labps/` ใช้ stdlib เท่านั้น — `main.go` บาง, logic อยู่ใน `internal/proc` (อ่าน procfs จาก root path ที่กำหนด) และ `internal/render` (ตาราง/JSON ลง `io.Writer`) บทเรียนแต่ละบทอธิบายสถานะโค้ดในบทนั้นโดยอ้างโค้ดสุดท้ายใน repo; CI เพิ่ม job `go` ใน `ci.yml` ส่วน `pages.yml` ไม่เปลี่ยน

**Tech Stack:** Go 1.27 (stdlib), MkDocs Material 9.x, GitHub Actions (`actions/setup-go@v7`)

**Spec:** `specs/2026-11-15-go-track-design.md`

## Global Constraints

- stdlib เท่านั้น — ห้ามเพิ่ม dependency แม้ตัวเดียว (`go.mod` ไม่มี `require`)
- `go.mod`: `module github.com/sakzeed/opencode-lab/labs/labps`, `go 1.27`
- CLI: `labps --version` และ `labps list [--limit N] [--sort pid|rss] [--json] [--workers N]`; default `--limit 0`, `--sort pid`
- ตารางคอลัมน์ `PID PPID STATE RSS_KB NAME`; JSON field `pid`, `ppid`, `state`, `rss_kb`, `name`
- exit code: `0` สำเร็จ, `1` runtime error, `2` usage error
- อ่านเฉพาะ `/proc/<pid>/status` (Name/State/PPid/VmRSS); process ที่หายระหว่างอ่านต้องถูกข้าม ไม่ทำให้ list fail
- แต่ละบท: H1 เดียว, 3 แบบฝึกหัด, 2 คำถามเช็คความเข้าใจ, สรุป, caveat proot, output จากเครื่องจริง
- ห้ามตัวอย่างที่ใช้ `jq`, `file`, `htop`; ห้ามอ้างว่า `go test -race` ใช้ได้
- validator: `ok: 18 pages`; `mkdocs build --strict` ผ่าน

## ความต่างจาก design ที่พบตอนลงมือ (เครื่องนี้)

- เครื่องที่ลงมือเป็น **Ubuntu 24.04 (proot, aarch64)** ไม่ใช่ Debian 13 — บท Go ต้องบอกชื่อเครื่องตามจริง
- `/usr/bin/go` เป็น 1.22.2; ติดตั้ง Go 1.27.4 ไว้ที่ `~/.local/opt/go-v1.27.4` + symlink `~/.local/opt/go` (แตกจาก toolchain zip ใน module cache เพราะ binary ใน cache ไม่มี exec bit บน proot)
- `go test -race` fail ด้วย `FATAL: Found 39 - Supported 48` (ThreadSanitizer ไม่รองรับ VMA 39 บิตของ kernel Android) ไม่ใช่ linker error — บทที่ 3 แสดง error ตัวนี้
- `/proc` เห็น ~22 entries

## Review Focus

- **process ตายระหว่าง `ReadDir` กับ `ReadFile`** → ต้องข้าม (`errors.Is(err, fs.ErrNotExist)`) — test `TestListSkipsVanished` ใช้ fixture ที่มี dir แต่ไม่มี `status`
- **`VmRSS` ไม่มี (kernel thread/zombie)** → `RSSKB` = 0 ไม่ใช่ error — test `TestParseStatusNoVmRSS`
- **flag ผิด/ค่า `--sort` ไม่รู้จัก/`--limit` ติดลบ** → exit 2 พร้อมข้อความ usage ลง stderr — test `TestRunUsageErrors`
- **ชื่อ process มีช่องว่าง/ยาว** (`Name:\tWeb Content`) → ตารางต้องไม่เลื่อนคอลัมน์ (NAME อยู่ท้าย) และ JSON ต้อง escape ถูก — fixture pid 300 ชื่อมีช่องว่าง
- **`ListConcurrent` ต้องให้ผลเหมือน `List` (เรียงเท่ากัน) และหยุดเมื่อ ctx ถูกยกเลิก** — test `TestListConcurrentMatchesList`, `TestListConcurrentCanceled`
