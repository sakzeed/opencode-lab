## Review Focus

- **คำกล่าวอ้างเรื่อง proot ต้องตรงกับที่ทดสอบ**: Ctrl-Z suspend ได้ interactively แต่ `kill -STOP` จาก script ไม่ suspend (state ยัง `S`) — ต้องไม่เขียนขัดกันเอง
- **ตัวอย่าง `pkill -f` ต้องเตือนว่าฆ่า shell ตัวเองได้** เพราะ pattern ไป match command line ของ shell (ทดสอบแล้ว exit 143)
- **zombie ต้องอธิบายว่าฆ่าไม่ได้และ `kill -0` ยังคืน 0** ไม่ใช่ "process ตายแล้ว"
- **ตัวเลข 3 บท → 4 บท** ต้องตรงกันใน `docs/index.md`, `README.md` และ nav
- **validator false positive**: ข้อความไทยที่ติดกับอังกฤษโดยไม่มีช่องว่างจะถูกจับ — ต้องเว้นวรรคให้ถูก
- **Pages ครั้งแรกหลังเพิ่มหน้า** อาจ 404 ระยะสั้น — poll ไม่ใช่สรุปว่า fail

```
# Linux บทที่ 4: process, signal และ job control
## 4.1 process คืออะไร — PID, PPID และ state
## 4.2 /proc/<pid> — แหล่งความจริงที่ไม่ต้องมี strace

## 4.8 แบบฝึกหัด 4 ข้อ + เช็คความเข้าใจ 3 ข้อ
## สรุปบทที่ 4
```

ค่าที่ต้องใส่ (คัดจากของจริง ห้ามแต่ง):

| หัวข้อ | หลักฐานที่ต้องปรากฏ |
|---|---|
| state table | `R`, `S`, `D`, `T`, `Z` พร้อมความหมาย |
| proc view | `ps aux \| wc -l` → 44; `ps -eo pid,ppid,stat,comm --sort=pid \| head -6` แสดง `Z` + `<defunct>` |
| top | `Tasks: 42 total, … 31 zombie` |
| /proc | `/proc/$$/status` (`State: S`), `cmdline` คั่นด้วย NUL, `readlink cwd` → `/root`, `fd` → `/dev/null` + pipes |
| signals | `kill -l` 1–20; TERM trap → `CAUGHT-TERM`, `exit=0`; SIGKILL → `exit=137`; `timeout 1 sleep 5` → `124`; `wait` → `143` |
| job control | transcript: `Ctrl-Z` → `[1]+ Stopped sleep 60`; `jobs`; `bg %1`; `jobs` → `Running`; `fg %1`; `Ctrl-C` |
| งานยาว | orphan/nohup → `ps` แสดง `PPID 1`; `setsid` → SID เป็นของตัวเอง (`20431 20407 20431 sleep`); `renice` → `NI 5` |
| pkill | `pgrep -a -f` เห็น shell ตัวเอง + `sleep`; `pkill -f` ฆ่า shell (exit 143); ทางปลอดภัย `pgrep -a -x sleep` / `pkill -x sleep` |
| zombie | python fork → `Z`, `kill -0` คืน 0, ฆ่าไม่หาย, หายเมื่อ parent exit |
| runaway lab | `yes > /dev/null &` → `ps -o pid,pcpu,stat,comm` → `R`; `kill -TERM` → GONE, exit 143; `kill -KILL` → exit 137 |

ต้องมี blockquote caveat ของ proot อย่างน้อย 3 จุด: process view/หน่วยความจำ, `kill -STOP` จาก script ไม่ suspend, ไม่มี `htop`/`strace`/`ss`/`tmux`/`systemd`
